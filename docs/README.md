# Introduction

This book is the technical documentation of the **Wazuh Manager** and of the agent components built
from the same repository. It is organized in three parts:

- [Development Documentation](dev/setup.md) — setting up an environment, building, running and packaging from
  sources, and running the tests.
- [User Guides](guide/README.md) — operational guides, chiefly the migration from 4.x to 5.x.
- [Reference Manual](ref/README.md) — what the manager is, its architecture, installation,
  configuration, every module, and the lifecycle operations (upgrade, uninstall, back up and restore).
