# Agent Management

This section describes how to manage Wazuh agents from the Wazuh manager, including centralized configuration distribution and agent group management.

- [Centralized Configuration](centralized-configuration.md) – Push configuration settings from the manager to agents, and check them with `verify-agent-conf`.
- [Agent Groups](agent-groups.md) – Organize agents into groups, through the API or `agent_groups`.

Related:

- [Control](../control/README.md) – Restarting and reloading agents from the API.
- [Agent Upgrade](../agent_upgrade/README.md) – Remote agent upgrades.
