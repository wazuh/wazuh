Why this matters for the spike: the issue's "graceful degradation" and "LSM vs kprobe fallback" questions already have in-tree precedent for file events — a runtime ladder ending in a switch to a completely different backend (Linux Audit). For the new module the audit escape hatch does not exist for exec/network events, so the ladder's bottom rung must be redesigned (that's angle 5 + 8/10 of the issue).
