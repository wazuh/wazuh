How one file event travels from the kernel to FIM today

Issue #37396 · sequence diagram (current code, startup + steady state)

Two decoupled threads inside the engine: the ring-buffer poll thread converts and enqueues; a drain thread dequeues and calls into FIM. The bounded queue between them is today's only backpressure mechanism (drops when full — logged once).
